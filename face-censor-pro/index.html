Note : Face Censor Pro est un projet personnel, réalisé en bonus en dehors du cadre du projet « Creative Code ». Il n'entre pas dans le barème et n'est pas à prendre en compte dans la note.

Le serveur Python fait tourner InsightFace (RetinaFace) en scan multi-échelle : l'image est analysée entière puis redécoupée en tuiles à pleine résolution, ce qui repère aussi bien les gros plans que les visages lointains dans une foule.
